[Fable](https://www.fablepod.com/?ref=taqib.dev) is an iOS app that turns articles and documents into podcasts. I worked on the frontend and built the website. It was my first mobile app and my first time using React Native and Expo.

## Getting started with React Native

Someone else had already started the app when I joined, so I picked up the existing codebase and implemented the designs for the iOS frontend. Expo Router handled navigation, NativeWind handled styling, and we used Zustand for things like the player state. I was also using GraphQL through Apollo Client for the first time.

The Expo setup felt familiar once I got my bearings. There was file-based routing and I could style screens with Tailwind classes. I had more to learn about what I could test in Expo Go and what needed a native build.

## Share to Fable

The hardest feature I worked on was the iOS share extension. If someone tapped Share on a document in Files or another app, they could choose Fable and land on the Create screen with the file already attached.

This was my first time working in Xcode. The extension runs as its own target, so I had to set up an App Group that both the extension and the app could access. The extension copied the file into the shared container and opened Fable with a deep link. The app could then pick up the file and show it on the Create screen. I wrote about figuring that out in [Share to Fable](/blog/share-to-fable).

Expo now has an experimental config plugin for receiving shares. On iOS it opens the main app from the share extension, which Apple doesn’t officially support. [Expo Sharing docs](https://docs.expo.dev/versions/latest/sdk/sharing/#sharing-to-your-app-from-other-apps)

## Getting onto the App Store

The hardest and most interesting part overall was getting the app onto the App Store. I had to learn App Store Connect and how signing certificates and provisioning profiles fit together. The share extension was another target that needed its own signing and entitlements.

We used EAS to make development and production builds and submit the app to App Store Connect. Getting used to that whole process was a big part of building my first iOS app.
