[Fable](https://www.fablepod.com/?ref=taqib.dev) is an iOS app that turns articles and documents into podcasts. I worked on the frontend and built the website. It was my first time doing any form of iOS development.

## Getting started

The app was built with Expo and React Native, with Zustand for things like the player state and GraphQL through Apollo Client. It was my first time using React Native and my first time using GraphQL. Someone else had already started the app when I joined, so I picked up the existing codebase and implemented the designs for the iOS frontend.

Coming from Next.js, Expo was easy to get into. File-based routing, Tailwind classes and React all carried over from the web. Most of the learning was working out which packages and features needed a native build through Xcode, and what I could run in Expo Go.

## Share to Fable

The hardest feature I worked on was the iOS share extension. If someone tapped Share on a document in Files or another app, they could choose Fable and land on the Create screen with the file already attached.

The extension runs as its own target, so I had to set up an App Group that both the extension and the app could access. The extension copied the file into the shared container and opened Fable with a deep link. The app could then pick up the file and show it on the Create screen. I wrote about figuring that out in [Share to Fable](/blog/share-to-fable).

Expo now has an experimental config plugin for receiving shares. On iOS it opens the main app from the share extension, which Apple doesn’t officially support. [Expo Sharing docs](https://docs.expo.dev/versions/latest/sdk/sharing/#sharing-to-your-app-from-other-apps)

## Getting into the App Store

The hardest and most interesting part overall was getting the app onto the App Store. I had to learn App Store Connect and how signing certificates and provisioning profiles fit together. The share extension was another target that needed its own signing and entitlements.

We used EAS to make development and production builds and submit the app to App Store Connect.
